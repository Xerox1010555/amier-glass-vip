# AMIER — Glass Edition (VIP)

A second, VIP edition of the Amier portfolio: velvet night, frosted glass,
champagne gold — with a slowly gliding 3D glass scene (Three.js, transmission
gemstones, gold rings, gold dust) reacting to the cursor with heavy damping.

Static single-page site: no build step, no tracker, hardened headers.

- Live: https://amier-glass-vip.vercel.app
- Sibling edition: https://amier-3d-portfolio.vercel.app (Paper & Ink editorial)

## Stack
- Vanilla HTML/CSS/JS module + Three.js 0.170 (CDN importmap, CSP-whitelisted)
- Google Fonts: Cormorant Garamond + Manrope
- Vercel static hosting with strict CSP, HSTS, nosniff, X-Frame-Options

## Data
`js/data.js` mirrors the flagship portfolio data (12 live deployments + the
flagship itself as the 13th card). All links are real and verifiable.
